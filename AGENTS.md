# Repository Guide

## Repository Overview

This repository builds Posit Workbench container images for managed cloud platforms using Posit Bakery.

For changes to `bakery.yaml`, image templates, versions, or CI workflows, follow the [Bakery skill](https://github.com/posit-dev/images-shared/blob/main/plugins/bakery/skills/bakery/SKILL.md).

Do not make changes directly on `main`; use a topic branch.
